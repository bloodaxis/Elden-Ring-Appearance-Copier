# Elden Ring Appearance Copier 0.1.0

Initial public release.

- Copy appearance data between Elden Ring characters and favorite slots.
- Import and export compatible Elden Bling JSON appearance files.
- Stage multiple edits before saving and undo up to 20 operations.
- Preserve a backup when overwriting an existing save.
- Run on Linux or Windows using system Python, with optional launch-time installation of a private Python environment.

Extract the archive, then run `run.sh` on Linux or `run.bat` on Windows.
